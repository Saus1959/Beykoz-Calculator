# Beykoz calculator

    npm install
    npm run dev      # разработка
    npm run build    # сборка в dist/ — эту папку деплоить (Netlify, Vercel, GitHub Pages)

Цены в src/data.js прочитаны с фото меню и могут быть неточными — поправь их в приложении
(галочка «менять цены») или прямо в data.js. Данные хранятся в localStorage.
